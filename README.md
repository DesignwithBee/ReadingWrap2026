# ReadingWrap2026
Reading Wrap 2026 - all the books i have read in 2026 

Cool Girl Literature — a literary blog for the wellread and still curious.

Live site: https://designwithbee.github.io/ReadingWrap2026/

Vines are from Canva's free media library; book covers belong to their publishers. All illustrations belong to Bijoya D. 

Long term goal: Multi source reading data integration
Allow readers to import their reading history and statistics from platforms such as Goodreads, Calibre and supported e-readers, then generate a personalized Reading Wrapped through data aggregation and visualization.
